# 桌面提醒

一个轻量、免安装的 Windows 桌面提醒工具。设置时间与提醒内容后，程序会在屏幕底部播放几何小猫动画；主窗口关闭后仍驻留在系统托盘。

## 功能

- 支持一次提醒和按星期重复提醒。
- 周一至周五会在列表中简写为“工作日”。
- 一次提醒播放结束后自动从提醒列表和本地数据中删除。
- 支持上班、透气、喝水、吃饭、拉伸、散步、如厕、下班八种快捷状态。
- 根据提醒内容中的关键词自动选择动画，其他内容使用通用小猫提醒。
- 提示框按照“时间 + 提醒文字”的实际宽度自动调整。
- 支持开机自动启动、托盘后台运行、手动删除提醒。

## 使用方法

1. 双击 `桌面提醒.exe`。
2. 选择“一次提醒”或“重复提醒”。
3. 设置时间；重复提醒还需选择星期。
4. 输入提醒内容，或点击快捷状态自动填入。
5. 点击“保存提醒”。

关闭主窗口不会退出程序。要彻底退出，请右键任务栏通知区域中的猫猫图标，选择“退出”。

## 动画关键词

| 场景 | 可识别关键词示例 |
| --- | --- |
| 上班 | 上班、开工、开始工作 |
| 透气 | 透气、通风、窗 |
| 喝水 | 喝水、饮水、补水 |
| 吃饭 | 吃饭、用餐、早餐、午饭、晚饭 |
| 拉伸 | 伸懒腰、拉伸、伸展 |
| 散步 | 走走、散步、活动、走动、出去 |
| 如厕 | 拉屎、如厕、厕所、便便 |
| 下班 | 下班、收拾、回家 |

动画会自动结束，也可单击动画或按 `Esc` 提前关闭。

## 提醒规则

- 程序每 15 秒检查一次是否有到期提醒。
- 一次提醒必须设置为未来时间；到期后 24 小时内启动程序仍会补弹，播放结束后自动删除。
- 重复提醒仅在所选星期触发，同一天只触发一次。
- 多个提醒同时到期时依次处理，当前动画关闭后才会显示下一条。

## 数据与开机启动

提醒数据保存在：

```text
%LOCALAPPDATA%\DesktopReminder\reminders-v2.json
```

读取失败时，程序会在同一目录创建带时间戳的 `.broken-*` 备份，并以空列表继续运行。

“开机自动启动”通过当前用户注册表项实现：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DesktopReminder
```

移动程序目录后，应重新取消并勾选一次“开机自动启动”，以更新启动路径。

## 开发与构建

项目使用 C# WinForms 和 .NET Framework 自带编译器，不依赖 NuGet。开发构建：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出位于 `dist\DesktopReminder.exe`，所需资源会同步到 `dist\assets`。详细架构、预览、测试与发布方法见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 系统要求

- Windows 10 或 Windows 11
- .NET Framework 4.x
- 主程序与 `assets` 文件夹保持相对位置不变
