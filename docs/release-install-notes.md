## macOS: first launch / Mac 首次打开

**English:** PurrCue is currently unsigned and not notarized by Apple. If macOS blocks the first launch, click **Done**, then open **System Settings → Privacy & Security → Open Anyway** beside the PurrCue notice and confirm. A paid developer account is not needed to install. [Apple's instructions](https://support.apple.com/en-us/102445).

**简体中文：** PurrCue 当前未签名、未经过 Apple 公证。首次打开若被拦截，先点 **“完成”**，再到 **系统设置 → 隐私与安全性**，在 PurrCue 提示旁点 **“仍要打开”** 并确认。安装使用不需要付费开发者账号。[Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**日本語：** PurrCue は現在、Apple の署名・公証を取得していません。初回起動がブロックされた場合は **「完了」** を押し、**システム設定 → プライバシーとセキュリティ** で PurrCue の通知にある **「このまま開く」** を選んで確認してください。インストールに有料の開発者アカウントは不要です。[Apple の説明](https://support.apple.com/ja-jp/102445)。

**한국어:** PurrCue는 현재 Apple 서명 및 공증을 받지 않았습니다. 첫 실행이 차단되면 **완료**를 누른 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 PurrCue 알림 옆의 **확인 없이 열기**를 선택하고 확인하세요. 설치에 유료 개발자 계정은 필요하지 않습니다. [Apple 안내](https://support.apple.com/ko-kr/102445).
